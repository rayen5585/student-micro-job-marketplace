# Student Micro-Job Marketplace

## Description
A web application that allows students to publish micro-jobs and submit proposals to complete jobs posted by other students.

## Technologies
- Angular
- Node.js
- Express.js
- Git and GitHub

## Project Structure
- `frontend/`: Angular application.
- `backend/`: Node.js and Express API.
- `docs/`: Project documentation.

## Main Features
- Student profiles, skills, and portfolios.
- Job creation and management.
- Proposal submission and status management.
- Job search, filtering, and sorting.

## Team Workflow
Each team member works on a dedicated Git branch. Changes are submitted through pull requests before being merged into `main`.
